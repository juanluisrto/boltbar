Try it

The real interface, in your browser.

Click into the bar and use the same keys as on your Mac. Replies are simulated here, and they explain Boltbar itself.

  1. ↵Send a message
  2. ↵Type again while it answers: it queues
  3. ↑↓Switch models, with the field empty
  4. ←→Then change the thinking effort
  5. escHide the bar
  6. ⌥spaceBring it back: a new chat, unless it’s still answering

Simulated in your browser: no model is called. The real Boltbar sends your message straight to OpenAI or Anthropic.

Features

A small bar with the whole toolkit.

⌥ Space

One shortcut, any app

The bar floats over whatever you are doing. Esc hides it, and if a reply is still coming, ⌥ Space brings it back where you left it.

↑ ↓ ← →

GPT and Claude, side by side

OpenAI and Anthropic models in one shortlist. Switch with the arrow keys and set the thinking effort without reaching for the mouse.

Keychain · CLI

Your keys, or your login

Use your own API keys, kept in the macOS Keychain, or the Codex and Claude Code logins you already have.

Queue

Keep typing

Write follow-ups while it answers. They wait above the field and go out together; Return on an empty field sends them right away.

PNG · PDF · TXT

Drop in anything

Paste, drop or pick images, PDFs and text files. They stay attached to the message, so follow-up questions still see them.

Web

Search with sources

Turn on the globe and the model searches when it needs to, answering with numbered citations and the sites it used.

History

Every chat, searchable

Previous conversations open inside the bar. Filter by any word you remember; accents and case don’t matter.

Swift

Truly native

Swift and AppKit, a 3 MB download, four themes and signed in-app updates. No Electron, no account.

Privacy

Yours, and only yours.

  • Keys stay in your Keychain. Boltbar never writes them to a file.
  • Chats stay on your Mac. History and attachments live in your Library folder, not in a cloud.
  • No account, no analytics. Boltbar talks to the provider you choose, and to GitHub to check for signed updates.

Install

Get Boltbar.

macOS 13 Ventura or later, on Apple Silicon or Intel. Bring an OpenAI or Anthropic API key, or sign in with the Codex or Claude Code CLI.

Download
