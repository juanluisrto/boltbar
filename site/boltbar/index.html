Ask anything, from anywhere.

Boltbar is a small, native chat bar for macOS. Press ⌥ Space in any app, ask GPT or Claude, and get back to what you were doing.

Download for Mac or curl -fsSL https://raw.githubusercontent.com/juanluisrto/boltbar/main/install.sh | sh

macOS 13+ · Apple Silicon and Intel · signed and notarized · MIT

Keys, ticked as you try them above
⌥ SpaceOpen Boltbar over any app. If a reply is still coming, it returns where you left it.
escHide it.
↵Send. ⇧ ↵ adds a line.

Also

accounts
Your OpenAI or Anthropic API keys, kept in the Keychain, or the Codex and Claude Code logins you already have.
attachments
Paste, drop or pick images, PDFs and text files. They stay with the message for follow-up questions.
web
Turn on the globe and the model searches when it needs to, citing its sources.
themes
Paper, Mist, Graphite and Midnight, with any accent colour.
size
Swift and AppKit. A 3 MB download, no Electron, no account.
updates
Signed, in-app, installed when you choose.

Privacy

Your keys stay in the Keychain. Chats and attachments stay on your Mac, in ~/Library/Application Support/Boltbar. Boltbar talks to the provider you choose and to GitHub to check for updates. There are no analytics.

Install

Download the signed DMG or ZIP from the latest release, or run:

curl -fsSL https://raw.githubusercontent.com/juanluisrto/boltbar/main/install.sh | sh

The script checks the release checksum and keeps any previous version as a backup. Boltbar needs macOS 13 Ventura or later, and an OpenAI or Anthropic API key or a Codex or Claude Code login.
